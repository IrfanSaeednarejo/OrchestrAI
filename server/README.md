# OrchestrAI
A production-inspired stateful multi-agent orchestration platform for autonomous customer support, built with LangGraph and TypeScript.

## Local Infrastructure
- Prerequisite: Docker Engine + Compose plugin running
- Command to start: `docker compose up -d`
- Command to check status: `docker compose ps`
- Command to view logs: `docker compose logs -f`
- Command to stop: `docker compose down`
- Command to stop AND wipe data volumes: `docker compose down -v`
