# Northvale Domestic Orders and Returns Policy
## Who qualifies for a domestic standard return?

Customers with a verified domestic US address qualify for a domestic standard return within the standard 30 days window. Electronics items must be returned within a shortened 15 days window instead. Bulk returns require a mandatory 14 days advance notice submitted through support channels before initiating the process. Standard returns apply strictly to eligible domestic orders meeting all policy criteria. Northvale evaluates each submission against these defined eligibility thresholds.

## When does the domestic return eligibility clock start?

The domestic return eligibility clock starts officially on the date of carrier delivery confirmation. Weekend or holiday delivery dates are fully included in the standard counting rules without exception. Customers must monitor their delivery notices to accurately track the expiration of the return window. Northvale relies on official carrier delivery timestamps to determine the start of the return period. All return submissions must be completed before this calculated eligibility clock expires.

## What condition must domestic return items be in?

Domestic return items must arrive in unworn, unwashed condition with all original tags attached. Packaging integrity expectations require that items retain their original boxes and protective materials where applicable. Used, altered, or damaged items fail inspection and face rejection at the warehouse. Northvale inspects every returned parcel to verify that these strict physical condition requirements are fully met. Customers must ensure proper handling before shipping items back to the warehouse.

## How do I generate a prepaid domestic return shipping label?

Customers can generate a prepaid domestic return shipping label directly through the online customer portal. The system makes the requested shipping label available within a 24 hours SLA after request submission. Customers must print and attach this official label securely to the outside of the return parcel. Northvale provides this portal mechanism to streamline the domestic return shipping process for everyone. Unused labels generated through the system require no further action if the return is canceled.

## How much is deducted for domestic return shipping?

The shipping deduction for a domestic return is set at $6.95 for the first item and $2.50 for each additional item included in the parcel. Defective items or wrong items received are completely exempt from these return shipping label fees. Northvale applies these specific deductions automatically during the final refund calculation phase. Customers reviewing their return summaries will see these exact fees itemized transparently. This fee structure covers standard carrier transportation costs back to the warehouse facility.

## Where can I drop off a domestic return package?

Customers can drop off a domestic return package at any authorized carrier drop-off location within the network. Customers must retain their official drop-off receipt as proof of handover for future reference. The tracking activation scan occurs immediately upon carrier receipt at the designated drop-off facility. Northvale strongly advises keeping this receipt until the return refund is fully settled. This physical drop-off step initiates the return transit phase back to Northvale.

## How should I pack multiple items into one domestic return?

Multiple items can be packed into a single consolidated box under standard domestic return rules rather than creating separate RMAs. The additional-item shipping fee calculation applies the $2.50 rate for every extra item included in the box. Customers must ensure all items correspond to authorized return requests within the portal system. Northvale processes consolidated parcels efficiently upon arrival at the central warehouse inspection dock. Proper packing prevents item damage and ensures accurate warehouse intake scanning.

## When is signature-verified intake required for a domestic return?

Signature-verified intake is required for any domestic return that meets or exceeds the $500 high-value threshold at the intake dock. This strict procedure ensures complete chain-of-custody protection for all high-value parcels during warehouse arrival. Carrier personnel must obtain a verified signature upon delivering these expensive parcels to the facility. Northvale mandates this extra security measure to safeguard valuable inventory against loss or misplacement. Customers shipping expensive merchandise should verify that the carrier applies signature confirmation.

## How does warehouse inspection grading work upon arrival?

Warehouse inspection grading begins with an initial intake scan followed by detailed physical grading steps. The facility completes the inspection and renders a decision within a strict 48 hours SLA after warehouse receipt. Graders evaluate item condition against original manufacturing specifications to determine restocking eligibility. Northvale applies these standardized grading criteria to every incoming domestic return parcel. The inspection outcome directly determines the final refund amount issued to the customer.

## What deductions apply if components or packaging are missing?

A missing-component deduction cap of 25% and a damaged-packaging fee of 15% apply when items arrive incomplete or compromised. These specific percentage deductions reflect the reduced resale value of the returned merchandise. Northvale provides an itemized deduction breakdown within the official confirmation email sent to the customer. Customers can review these calculated fees directly in the post-inspection notification message. Proper handling and complete packaging prevent these avoidable deductions from occurring.

## What happens if a domestic return arrives after the window closes?

Discretionary late-return intake permits processing for parcels arriving after the official return window has closed. Northvale applies a mandatory late-return restocking fee of 50% to all items received past the deadline. This fee is automatically deducted from the final refund amount issued for the late submission. Customers are encouraged to ship returns promptly to avoid incurring this substantial financial penalty. Late parcels that fail discretionary review are returned to the sender at their expense.

## How long does a domestic return refund take to settle?

Refund settlement timelines vary by payment method, requiring 5 to 7 business days for standard processing, 10 business days for debit cards, 3 business days for ACH, 48 hours for PayPal, and 5 business days for Klarna. The settlement clock starts immediately after warehouse inspection approval is officially granted in the system. Northvale initiates the transfer through the original payment processor without unnecessary delay. Customers should consult their respective financial institutions for final credit visibility.

## Can I cancel a domestic return request before shipping it?

Customers can easily cancel a domestic return request through the online portal before the carrier scans the label. Unused labels incur no shipping deduction whatsoever since the carrier never processed the parcel. Northvale automatically closes the return case once the cancellation is confirmed in the system. Customers who decide to keep their items do not need to take any further action. A new return request must be submitted later if the item needs to be sent back.

## What should I do if my domestic return tracking stalls in transit?

Customers must present their drop-off receipt as proof to initiate a carrier investigation when tracking stalls in transit. The support escalation path activates once the carrier officially opens a formal trace on the missing parcel. Northvale customer support assists in coordinating with the carrier to locate the delayed shipment. Customers should maintain open communication with support agents throughout the ongoing investigation process. Official carrier documentation is essential for resolving transit discrepancies successfully.

## How are restocked domestic items processed for quality assurance?

Warehouse restocking versus liquidation triage determines the exact quality assurance path for every processed item. Northvale ensures that the customer refund is entirely independent of the subsequent resale disposition decision. Items meeting strict quality standards are restocked for inventory, while others are routed to liquidation. Northvale maintains rigorous oversight during this final triage phase to uphold inventory standards. This procedure completes the comprehensive domestic return lifecycle within the facility.
