# Account Security and Verification FAQ

## What is email verification and why is it required?

Email verification is required for high-risk operations such as password changes, email updates, and sensitive profile modifications.

## How does the verification code process work?

A 6-digit one-time code is sent to the verified email on file. The code expires after 10 minutes.

## How many verification attempts are permitted?

Maximum of 3 failed verification attempts before the code is invalidated. A new code must then be requested.
